Siguiente: descargar mis partidas

Tus keys son personales: no las compartas ni las publiques en capturas de pantalla. Se guardan en el archivo .env de la carpeta del programa y nunca se vuelven a mostrar completas.

Cómo conseguir tu key de Riot
  1. Entra a developer.riotgames.com e inicia sesión con tu cuenta de Riot (la misma con la que juegas). Acepta los términos si te los pide.
  2. En la página principal verás un recuadro llamado «Development API Key». Pulsa el botón de copiar, o selecciona el texto que empieza con RGAPI- y cópialo.
  3. Vuelve aquí, pégala en «Key de Riot» y pulsa «Probar key de Riot».
  4. Si dice que funciona, pulsa «Guardar».

Esta key dura 24 horas. Cuando expire, entra de nuevo a esa página, pulsa «Regenerate API Key», copia la nueva y pégala aquí. Lo que ya descargaste no se pierde.

Una key que no expira (Personal API Key)
  1. En developer.riotgames.com busca «Register Product» y elige «Personal API Key». Los nombres de los botones pueden cambiar un poco.
  2. Rellena el formulario contando que es una herramienta personal para analizar tus propias partidas. Es gratis.
  3. Riot la revisa y puede tardar unos días. Mientras tanto, usa la Development API Key de arriba.
  4. Cuando te la aprueben, pégala aquí, marca la casilla «Mi key es una Personal API Key» y pulsa «Guardar».
Cómo conseguir tu key de Gemini (opcional)
  1. Entra a aistudio.google.com/apikey con tu cuenta de Google.
  2. Pulsa «Create API key» (crear clave de API) y espera unos segundos.
  3. Copia la key que aparece, pégala en «Key de Gemini» y pulsa «Guardar».
